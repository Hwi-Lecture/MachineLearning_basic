### 데이터 기본 정보

**표 컬럼 기본 정보**


| 컬럼 | 뜻 |
|---|---|
| `PassengerId` | 승객 번호 |
| `Survived` | **생존 여부 (정답)** — 0=사망, 1=생존 |
| `Pclass` | 객실 등급 (1 / 2 / 3) |
| `Name` | 이름 |
| `Sex` | 성별 |
| `Age` | 나이 |
| `SibSp` | 함께 탄 형제자매 + 배우자 수 |
| `Parch` | 함께 탄 부모 + 자녀 수 |
| `Ticket` | 티켓 번호 |
| `Fare` | 요금 |
| `Cabin` | 객실 번호 |
| `Embarked` | 탑승 항구 (C / Q / S) |
