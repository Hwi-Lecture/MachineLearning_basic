## Pima diabetes 설명
---
| 변수 | 의미 | 알아두면 좋은 도메인 지식 |
| --- | --- | --- |
| Pregnancies | 임신 횟수 | 임신 자체보다는 임신 과정에서 발생하는 인슐린 저항성, 임신성 당뇨 경험 등이 이후 제2형 당뇨 위험과 관련될 수 있음 |
| Glucose | 포도당 | 인슐린이 포도당을 세포 안으로 보내 에너지로 쓰게 만들지만, 인슐린 기능에 문제가 생기면 혈중 농도가 높아져 당뇨병 발생 가능 |
| BloodPressure | 이완기 혈압(mmHg) | 고혈압은 당뇨와 함께 대사·심혈관 위험과 관련됨. |
| SkinThickness | 삼두근 피부주름 두께(mm) | 체지방량을 간접적으로 추정하는 지표. |
| Insulin | 인슐린 | 혈당을 낮추기 위해 분비되는 호르몬. |
| BMI | 체질량지수 | 비만도를 나타내는 대표 지표. 높을수록 당뇨 위험도 증가 |
| DiabetesPedigreeFunction | 당뇨 가족력 점수 | 부모·친척 등의 당뇨 가족력을 수치화한 변수. |
| Age | 나이 | 일반적으로 나이가 증가할수록 제2형 당뇨 위험도 증가 |
| Outcome | 당뇨 여부 | 0 = 비당뇨, 1 = 당뇨 |
---
### 배경 지식
* 정상 흐름

음식을 먹는다 -> 혈당 상승 -> 췌장에서 인슐린 분비 -> 인슐린이 세포에 포도당을 흡수하라는 신호를 보냄 -> 혈당 감소

* 인슐린 저항성이 생기면

혈당 상승 -> 인슐린 분비 -> 세포가 인슐린에 반응하지 않음 -> 혈당이 감소되지 않음 -> 당뇨병

* Gluecose 수치 평가 (절대적이진 않음)
    * 정상 : 140mg/dL 미만
    * 당뇨 위험 : 140-199mg/dL
    * 당뇨 : 200 mg/dL 이상
